## Prompt 29 — Automatska dokumentacija za Terraform module

```text
Add automated Terraform module documentation support.

Goal:
Standardize README documentation for all Terraform modules.

Tasks:
1. Add .terraform-docs.yml at repository root.
2. Update module README files to include generated sections using markers:
   <!-- BEGIN_TF_DOCS -->
   <!-- END_TF_DOCS -->

3. Add scripts/docs.sh:
   - Finds all Terraform module directories under modules/.
   - Runs terraform-docs markdown table on each module.
   - Updates README.md files.
   - Prints modules that were updated.

4. Add Makefile target:
   - make docs

5. Update docs/module-conventions.md:
   - Explain README format.
   - Explain terraform-docs usage.
   - Explain required module examples.

README structure per module:
- Title
- Purpose
- Status
- Usage
- Requirements / Providers / Inputs / Outputs generated by terraform-docs
- Notes
- TODOs if partial

Rules:
- Do not remove existing useful documentation.
- Do not generate docs for live/ roots unless explicitly useful.
- Do not require cloud credentials.
- If terraform-docs is not installed, scripts/docs.sh must print a clear error.

Run:
- scripts/docs.sh if terraform-docs is available.
- Otherwise verify script behavior.

Final response:
- List updated docs.
- Mention whether terraform-docs was available.
- Mention any modules missing proper README markers.
```
