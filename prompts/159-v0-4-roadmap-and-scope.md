## Prompt 159 — v0.4 roadmap and scope

```text
Create v0.4.0 roadmap and scope documents.

Create:
- ROADMAP_V0.4.md
- RELEASE_PLAN_V0.4.md
- BACKLOG_V0.4.md

Theme:
ClusterForge v0.4 should focus on enterprise extensibility, fleet visibility, policy/compliance, and operational maturity.

ROADMAP_V0.4.md must include:

1. Goals:
   - plugin system MVP
   - template pack registry
   - policy engine v2
   - AWS multi-account support
   - multi-region metadata
   - platform upgrade planners
   - Terraform Cloud support
   - GitLab CI templates
   - service catalog
   - Backstage export
   - compliance mapping
   - air-gapped bundle manifest

2. Non-goals:
   - full SaaS
   - automatic remediation
   - global scheduler
   - plugin marketplace
   - compliance certification
   - automatic failover

3. Milestones:
   M1: v0.3 release gate and stabilization
   M2: plugin/template/policy extensibility
   M3: enterprise config model
   M4: upgrade and operations tooling
   M5: catalog/compliance/inventory
   M6: release hardening

4. Acceptance criteria:
   - plugin system tests pass
   - template registry tests pass
   - policy engine tests pass
   - golden generator tests pass
   - CLI e2e tests pass
   - docs cover new enterprise workflows
   - no secrets in generated files
   - release gate passes

5. Risks:
   - feature creep
   - plugin security
   - policy false positives
   - provider compatibility
   - enterprise complexity

BACKLOG_V0.4.md:
Group by:
- CLI
- Terraform modules
- Policy
- Security
- Compliance
- Fleet
- Docs
- Testing
- Release

Each item:
- priority
- complexity
- status
- acceptance criteria
- notes

Final response:
- Summarize recommended v0.4 scope.
- List must-have.
- List deferred.
```
