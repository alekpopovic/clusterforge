# Compliance control mappings

These documents map ClusterForge features to common control areas as an
implementation and evidence-planning aid. They do not claim or provide SOC 2,
ISO 27001, CIS, or NSA/CISA compliance, certification, attestation, legal advice,
or assurance that a control is designed or operating effectively.

Statuses mean: `implemented` (feature exists), `partial` (coverage is bounded),
`documented` (procedure only), `planned`, or `not covered`. Evidence source names
identify possible artifacts, not proof by themselves. Organizations must select
the applicable framework/version, validate scope, gather operating evidence,
manage exceptions, and obtain qualified legal/compliance/audit advice.
