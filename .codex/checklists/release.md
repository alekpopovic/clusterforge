# Release Checklist

- `VERSION`, `CHANGELOG.md`, and release docs are aligned.
- `VERSION_MATRIX.md` and `SMOKE_TEST_MATRIX.md` are honest.
- CLI tests pass.
- Terraform formatting and validation pass where possible.
- Release artifacts have checksums.
- SBOM/signing status is documented without overclaiming.
- No real release tag is pushed unless explicitly requested.
