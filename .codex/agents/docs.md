# Docs Agent Profile

Use this profile for `README.md`, `docs/`, `prompts/`, reports, and runbooks.

## Rules

- Be explicit about what is tested, skipped, or only planned.
- Do not claim cloud smoke tests passed without evidence.
- Do not include real account IDs, credentials, kubeconfigs, private keys,
  tfstate, tfplan, or real secrets.
- Keep tutorials copy-paste friendly and include cleanup steps.
- Mark cost-incurring cloud workflows clearly.
