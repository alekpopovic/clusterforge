# Roadmap v0.3

Theme: enterprise adoption, plugin system, advanced deployment strategies, and
UI/API exploration.

## Candidate Scope

- executable plugin prototype
- richer policy engine integration
- ECS blue/green hardening
- advanced Kubernetes workload modeling or GitOps-first alternatives
- import/adoption CLI prototype
- UI/API discovery spike for teams managing many environments

## Non-Goals

- hosted SaaS launch
- automatic production remediation
- marketplace for untrusted plugins

## Acceptance Criteria

- plugin security model documented and reviewed
- at least one advanced deployment strategy tested end to end
- enterprise adoption workflows have migration/import dry-run coverage
